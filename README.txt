EBOM MARKET TELEGRAM BOT

FITUR:
- /start dan /menu
- daftar produk dengan tombol
- keranjang
- konfirmasi pesanan
- pesanan otomatis dikirim ke Telegram admin
- tombol WhatsApp admin

CARA MENJALANKAN:
1. Buat bot melalui @BotFather dengan /newbot.
2. Simpan token bot.
3. Isi BOT_TOKEN.
4. Isi ADMIN_CHAT_ID dengan Telegram chat ID kamu.
5. npm install
6. npm start

CATATAN:
Produk dapat diubah di bagian PRODUCTS pada bot.js.
Untuk pembayaran otomatis, dapat ditambahkan kemudian.
Jangan membagikan BOT_TOKEN karena token dapat digunakan untuk mengendalikan bot.
